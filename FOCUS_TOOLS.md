# Focus Software Suggestions Used by the Recommendation Engine

The app can suggest optional third-party tools. These tools are not part of the ML classifier and are not required to run the project.

## Forest

Best for: focus sessions and intentional phone-free time.

Official site: https://www.forestapp.cc/

## Freedom

Best for: blocking distracting apps and websites across devices.

Official site: https://freedom.to/

## Cold Turkey

Best for: stricter desktop website/application blocking.

Official site: https://getcoldturkey.com/

## one sec

Best for: interrupting automatic social-media opening and passive app-use habits.

Official site: https://one-sec.app/

The recommendation engine chooses tools according to the user's platform, goal, and social-media trigger.
