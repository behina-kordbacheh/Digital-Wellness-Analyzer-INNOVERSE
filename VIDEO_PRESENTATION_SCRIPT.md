# 90-Second Video Presentation Script

## 0:00-0:08 — Hook
**Visual:** Logo + “Less scrolling. More living.”

**Voice-over:**
“Screen time is easy to measure. Healthy digital behavior is much harder to understand. Digital Wellness Analyzer uses explainable machine learning to turn everyday device habits into practical actions.”

## 0:08-0:19 — Problem
**Visual:** Three problem cards.

**Voice-over:**
“Most wellness tools stop at one message: use your phone less. But a student, a programmer, and a healthcare worker do not have the same digital routine. And a risk score without an explanation is not useful.”

## 0:19-0:33 — AI Architecture
**Visual:** Classification → Regression → Clustering → SHAP → Recommendation.

**Voice-over:**
“Our system combines five intelligence layers. Random Forest classifies digital behavior, regression estimates weekend screen time, K-Means identifies behavior segments, SHAP explains each prediction, and the recommendation engine turns that insight into an action plan.”

## 0:33-0:48 — Live Result
**Visual:** Model result dashboard, risk score, SHAP factors, weekend estimate.

**Voice-over:**
“For this user, the system detects a higher-risk usage pattern. Instead of treating that as a diagnosis, we display it as a model risk score and show exactly which behaviors influenced the result.”

## 0:48-1:03 — Personalized Action
**Visual:** Student + 30 minutes + evening + activity suggestions.

**Voice-over:**
“Then we ask a more useful question: what can this person do instead? Recommendations adapt to occupation, available time, goals, preferred activity style, and the reason they usually open social media.”

## 1:03-1:13 — Focus Tools
**Visual:** Forest, Freedom, Cold Turkey, one sec.

**Voice-over:**
“When extra friction helps, the system can also suggest focus tools such as Forest, Freedom, Cold Turkey, or one sec. These are optional tools, not sponsored recommendations.”

## 1:13-1:23 — Progress Loop
**Visual:** Analyze → Act → Review → Improve.

**Voice-over:**
“Each user signs into a local account, so their history returns when they reopen the app. Each completed analysis updates one daily snapshot. Missing days are shown as no data entered instead of being treated as zero usage. The My Progress dashboard shows check-in consistency, 7-day and 30-day summaries, 90-day trend charts, and month-to-month comparisons. No cloud AI API is required.”

## 1:23-1:30 — Closing
**Visual:** Logo + final statement.

**Voice-over:**
“Digital Wellness Analyzer does not just detect the habit. It explains it, estimates likely weekend use from the current behavior profile, and helps the user make a healthier next choice.”
